# Practical-02 – System Call Tracing Using strace

## Objective

To trace and analyze the system calls generated when executing:

    cat sample.txt

using the Linux `strace` command.

## Command Used

    strace cat sample.txt

## Important System Calls Observed

### 1. execve()

The execve() system call starts the cat program.

Example:

    execve("/usr/bin/cat", ["cat", "sample.txt"], ...)

It replaces the current process with the cat program.

### 2. openat()

The openat() system call opens files.

Example:

    openat(AT_FDCWD, "sample.txt", O_RDONLY|O_CLOEXEC) = 3

Here, sample.txt is opened in read-only mode.

The value 3 is the file descriptor returned for the file.

### 3. statx()

The statx() system call obtains information about a file.

For sample.txt, it obtains information such as:

- File type
- File permissions
- File size

The trace shows that sample.txt has a size of 41 bytes.

### 4. fstat()

The fstat() system call obtains information about an already opened file using its file descriptor.

### 5. splice()

The cat program in this trace uses splice() to transfer data efficiently.

The trace shows:

    splice(3, NULL, 5, NULL, 1048576, 0) = 41

followed by:

    splice(4, NULL, 1, NULL, 41, 0) = 41

This transfers the contents of sample.txt toward the terminal.

### 6. close()

The close() system call closes the file descriptors after the operation is completed.

Example:

    close(3)

### 7. exit_group()

The exit_group() system call terminates the cat process.

Example:

    exit_group(0)

The value 0 indicates successful termination.

## Other System Calls Observed

The trace also contains several system calls used during program startup and library loading, including:

- mmap()
- brk()
- access()
- read()
- mprotect()
- munmap()
- fcntl()
- ioctl()
- prlimit64()

These calls help the program load libraries, manage memory, inspect the system, and prepare for execution.

## User Space and Kernel Space

The cat command runs as a user-space program.

When cat needs services provided by the operating system, it uses system calls.

The Linux kernel handles these requests and returns the results to the program.

Basic flow:

    User Space
        |
        | System Calls
        v
    Kernel Space
        |
        v
    File System / Devices
        |
        v
    Kernel Space
        |
        v
    User Space

## Conclusion

The strace command successfully traced the system calls generated by cat sample.txt.

The trace shows how the operating system helps cat start execution, open and inspect the file, transfer its contents to the terminal, close resources, and terminate the process.
